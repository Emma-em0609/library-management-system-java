# Система управління бібліотекою (Java)

Курсова робота з дисципліни «Об'єктно-орієнтоване програмування».
Веб-застосунок для управління бібліотекою з авторизацією та розмежуванням прав доступу.

## Технології

- **Backend:** Java 17, Spring Boot
- **Безпека:** Spring Security, JWT
- **База даних:** PostgreSQL, Spring Data JPA
- **Документація:** Swagger (OpenAPI 3)
- **Контейнеризація:** Docker, Docker Compose
- **Тестування:** JUnit, Mockito

## Функціонал

- Реєстрація та авторизація користувачів через JWT
- Ролі: USER (перегляд) та ADMIN (повний доступ)
- CRUD операції для книг та читачів
- Облік видачі та повернення книг
- Swagger UI для тестування API

## Запуск через Docker

1. Клонуй репозиторій
2. Запусти:
   docker-compose up --build
3. Відкрий браузер: http://localhost:3000
4. Swagger UI: http://localhost:3000/swagger-ui.html
